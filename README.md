# GeyserRefine

面向 Geyser 互通服务器，为 Java 服务器上的基岩版（Geyser）玩家补充一些额外的功能。攻击机制只是其中一部分，整体还包括客户端体验、界面与辅助设置等。

功能构想与部分实现思路受 [GeyserExtras](https://github.com/GeyserExtras/GeyserExtras) 启发。

## 功能

### GeyserRefine-Paper（服务端）

面向基岩版玩家；在设置中开启"Java 版攻击"的玩家使用原版节奏。

- 攻击节奏：移除 1.9 攻击冷却，可无冷却连打
- 近战数值：武器伤害、冲刺暴击、生命回复贴近基岩版手感
- 击退：按基岩版手感调整（作用于玩家与生物）；末影龙、凋灵、监守者、铁傀儡、末地水晶、船、矿车、盔甲架等抗击退目标保持原版
- 跨类型连击保护：连续攻击使用 Java 战斗的对手时，伤害会随连击递减，避免无冷却连点优势过大；打怪与基岩玩家内战不受影响
- 命中反馈：近战命中时播放基岩版命中音效
- 隐藏基岩版不显示的 1.9+ 特效（横扫、伤害指示粒子等）
- 按触屏/手柄/键鼠自动适配方块交互距离

### GeyserRefine-Extension（客户端）

面向基岩玩家的界面与客户端功能：

- 暂停菜单的"服务器设置"会打开综合设置，可从这里一键快速重连
- 综合设置含辅助项：夜视、屏幕坐标、游玩天数、挖掘粒子、高级提示框、自定义头颅、链接前提示等；与 Paper 配对时还会显示攻击相关设置
- 主菜单：快速重连、进度、统计、辅助性设置、界面元素设置、灵魂出窍等
- 夜视：开启后持续生效；若已通过其他方式获得夜视则不会重复叠加
- 屏幕坐标与游玩天数默认开启，重进服务器仍会保留
- 灵魂出窍：让视角脱离身体自由飞行（WASD/空格/潜行/疾跑控制）
- 加入时的提示（Toast），内容可修改
- 可选资源包与披风显示（实验性）

## 安装

1. 将 `GeyserRefine-Paper.jar` 放入服务器 `plugins/`（需 floodgate-spigot；可选 packetevents）。
2. 将 `GeyserRefine-Extension.jar` 放入 Geyser 的 `extensions/`。
3. 两端在同一台机器时默认自动配对；之后重启服务器与 Geyser。

## 配对

两端通过 TCP 判断是否配对。配对运行是完整功能；单独运行各自保留可用功能：

| 场景 | 结果 |
|------|------|
| 仅 Paper | 战斗、击退、命中音效可用；`/geyserrefine settings` 打开内建表单（仅"切换 Java 攻击"） |
| 仅 Extension | 辅助/界面/夜视/坐标/游玩天数/灵魂出窍/Toast 等可用；攻击设置区隐藏 |
| 两端配对 | 全部功能 |

## 命令

`/geyserrefine`（别名 `/gr`）

- `settings`：打开设置（已配对时为完整菜单；未配对时为"切换 Java 攻击"）
- `reload`：重载配置
- `escape`：脱离卡死

## 配置文件

| 文件 | 属于 | 作用 |
|------|------|------|
| `plugins/GeyserRefine/config.yml` | Paper | 战斗数值、击退、连击保护等 |
| `plugins/GeyserRefine/playerdata.yml` | Paper | 玩家"Java 版攻击"等设置 |
| `extensions/geyserrefine/config.yml` | Extension | 灵魂出窍等开关 |
| `extensions/geyserrefine/toast.yml` | Extension | 加入提示的标题/内容/开关 |
| 两端各 `tcp.properties` | 两端 | TCP 端口、开关、日志 |

## 模块

| 模块 | 类型 | 说明 |
|------|------|------|
| GeyserRefine-Paper | Paper 插件 | 服务端机制 |
| GeyserRefine-Extension | Geyser 扩展 | 客户端功能与界面 |

## 构建

需要 JDK 17 与 Maven。

```
mvn clean package
```

产物：
- `GeyserRefine-Paper/target/GeyserRefine-Paper.jar`
- `GeyserRefine-Extension/target/GeyserRefine-Extension.jar`

## 依赖

编译期均为 provided，不随包分发：

- GeyserRefine-Paper：paper-api、floodgate api、packetevents（可选）
- GeyserRefine-Extension：geyser core、gson

## 模块间通信

- Paper 启动本机 TCP 服务端（默认端口 `25567`，见 `tcp.properties`）。
- Extension 作为 TCP 客户端连接该端口，用于同步如 `java-attack` 等设置。
- 未建立连接时两端自动降级为独立模式（见"配对"）。
